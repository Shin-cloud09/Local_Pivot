# Local Pivot — 인구감소지역 빈집 재생 정책 시뮬레이터

GitHub Pages 정적 배포용 5-Page 웹 애플리케이션입니다.

## 페이지 구성
1. `index.html` — **1. 문제인식 (Why)**: 전국 89개 인구감소지역 단계구분도(미거주주택·소멸위험지수·체류인구·카드소비) 및 3단 사업비 스펙트럼(철거 vs 빈집 리모델링 vs 공공임대 신축) 진단
2. `solution.html` — **2. 해결방안 (What)**: 89개 백분위·12개월 관광 데이터 기반 지역 유형 진단, 시범 3거점(단양·고흥·의성) 추이 차트, 실제 전환비·후보 주택 조사표, 전국 공공 사례 벤치마크 8건
3. `alternatives.html` — **3. 대안비교 (How)**: 대안별(A·B·C) 개별 초기 전환비·연간 운영비 설정, 1회 방문당 소비액 분리, 물리적 가동 객실일수 검산, 목표 달성 최소 조건 역산(Goal-Seek), **공무원용 자체 CSV 로컬 업로드 툴**
4. `report.html` — **4. 정책브리핑**: 5단계 정책 의사결정 브리핑, 현장 사전점검 체크리스트, 차트 포함 A4 사전검토 보고서 인쇄/PDF 및 CSV 출력
5. `audit.html` — **5. 데이터검증**: 전체 원천 데이터 다운로드, 실시간 JSON 무결성 검산, 시뮬레이터 산식·가정값 공개, 배제 데이터 품질 점검표

## 배포 주의사항 (폴더 구조 유지)
- 반드시 `index.html`과 함께 `css/`, `js/`, `data/` 하위 폴더 구조가 그대로 유지되도록 업로드해야 스타일과 지도가 정상 표시됩니다.
