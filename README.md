# Local Pivot — 인구감소지역 빈집 재생 정책 시뮬레이터 (v3)

처음 업무를 맡은 지자체 공무원도 쉽게 사용할 수 있도록 가독성과 단위를 전면 정비한 GitHub Pages 배포용 5-Page 웹 애플리케이션입니다.

## 주요 개선 내역 (v3)
- **금액 단위 `만 원` 전면 통일** 및 **방문 단위 `회` / 정착 단위 `명` 재정의** (`인회` 표현 완전 제거)
- **API 워터마크 없는 깔끔한 전국 230개 시군구 벡터 지도** 기본 제공 (선택 시 무료 OpenStreetMap 도로 배경지도 토글)
- **가독성 개편**: 장문 소제목 제거, 전폭 3단 정책 공백 카드, 챕터 2 전환비·후보주택 2단 요약 카드 및 필터형 공공 사례 벤치마크 카드(8건)
- **공무원 친화 시뮬레이터**: 기준 가동률(연간 운영일수) 명확한 정의, 대안별(A·B·C) 클릭 선택 카드 + 3년 누적 총사업비, 초심자용 빠른 예시 버튼, 목표 달성 역산 계산기, 결재란 포함 A4 사전검토 보고서

## 페이지 구성
1. `index.html` — 1. 현황 진단
2. `solution.html` — 2. 거점·사례
3. `alternatives.html` — 3. 대안 시뮬레이션
4. `report.html` — 4. 보고서 출력
5. `audit.html` — 5. 데이터 검증
